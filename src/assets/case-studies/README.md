# Case study images

Drop screenshots here and they show up automatically:

```
case-studies/
  zenty/
    cover.png    <- thumbnail on the /design card
    hero.png     <- wide image under the case study header
    step-1.png   <- image for process step 1 (also step-2, step-3, step-4)
  skinthesis/
  portfolio/
  todo-app/
```

`.png`, `.jpg`, `.jpeg`, `.webp`, and `.avif` all work. Any missing file falls back
to the designed stand-in. Export at 2x so text stays sharp.
